================================================================================
GIT HOOKS (Optional)
================================================================================

Location: .git/hooks/
Files: post-commit.ps1, post-push.ps1

These scripts can automatically send emails after git commits and pushes.
To enable them, you need to create Git hook wrappers:

1. Create .git/hooks/post-commit (no extension):
   #!/bin/sh
   powershell.exe -ExecutionPolicy Bypass -File .git/hooks/post-commit.ps1

2. Create .git/hooks/post-push (no extension):
   #!/bin/sh
   powershell.exe -ExecutionPolicy Bypass -File .git/hooks/post-push.ps1

Note: Currently hooks are in PowerShell only. Git hooks require shell scripts.

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Email config not found"
Solution: Run .\setup-email-notifications.ps1 or copy template to .email-config.json

Problem: "Failed to send email: Authentication failed"
Solution: Check app password is correct, verify Gmail allows app passwords

Problem: "Script cannot be loaded - execution policy"
Solution: Run: Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy Bypass

Problem: Emails not arriving
Solution: 
- Check spam folder
- Verify recipient emails are correct
- Test with .\notify.ps1 menu option 8 (Test Configuration)
- Check Gmail account is not locked

Problem: Unicode/emoji errors in PowerShell
Solution: All emojis removed from send-notification.ps1 to prevent encoding issues
