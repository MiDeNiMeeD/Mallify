sequenceDiagram
    autonumber
    actor U as Utilisateur
    participant S as Système

    rect rgb(255, 235, 235)
    Note over U,S: Étape 3 — Création du nouveau mot de passe
    U->>S: Saisir nouveau mot de passe
    U->>S: Saisir confirmation
    U->>S: Cliquer "Continue"
    S->>S: Valider (champs non vides, newPassword === confirm)
    alt Champs manquants
        S-->>U: Alerte "Please enter password and confirm it"
    else Mots de passe différents
        S-->>U: Alerte "Passwords do not match"
    else email ou code manquant
        S-->>U: Alerte "Missing email or verification code"
    else Validation OK
        S->>S: POST /auth/reset-password {email, code, newPassword}
        S->>S: Vérifier code OTP + expiration (vraie vérification ici)
        alt Code OTP invalide ou expiré
            S-->>U: Alerte "Could not reset password"
        else Code OTP valide
            S->>S: Hacher le nouveau mot de passe
            S->>S: Mettre à jour le mot de passe de l'utilisateur
            S->>S: Invalider le code OTP
            S-->>U: Alerte "Password reset successfully"
            S-->>U: Afficher l'écran Login
        end
    end
    end
